TankMate AI Android project — Prototype 0.1

اہم:
یہ ابھی مکمل War Machines bot نہیں ہے۔ یہ ایک ابتدائی Android dashboard ہے۔
اس میں ابھی game screen reading، enemy detection، auto aim، auto fire یا movement automation موجود نہیں۔

APK بنانے کا طریقہ (موبائل سے):
1) اس ZIP کو GitHub پر ایک نئے repository میں upload کریں۔
2) GitHub میں Actions کھولیں۔
3) "Build TankMate AI APK" workflow منتخب کریں اور Run workflow دبائیں۔
4) مکمل ہونے پر Artifacts میں TankMateAI-debug-apk.zip ڈاؤن لوڈ کریں۔
5) ZIP extract کریں، app-debug.apk پر tap کریں اور Android کی اجازت کے بعد install کریں۔

یہ debug APK ہوگا، Play Store release نہیں۔ Game automation کی اجازت، Android accessibility اور anti-cheat پابندیاں الگ سے جانچنی ہوں گی۔
